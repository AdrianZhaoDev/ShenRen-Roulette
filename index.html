指令与时间规则

q/w/e/r 对应导演按钮。短局数组在不能行动时顺序等待；长剧情作为导演调度按时执行。

hp/shield 需指定 target（我方 p1 / 敌方 p2）和 value：0 到 1 为最大值比例，大于 1 为绝对值。hp: 0 立即击倒，剧本随对局结束。

ult + target 只充满能量；stun + target + duration 眩晕若干秒，0 解除眩晕；speed + value 支持 0.5/1/1.5/2，长剧情固定 1×。

text + content 显示文字，可附 color；pause + duration 冻结若干现实秒后继续，手动暂停/继续可接管。

caption + content + duration 显示持续字幕，可附 chapter；长剧情的 guard + target + value 设置保活比例，finish 在 duration 秒指定一方退场。

长剧情默认自动点击弹反和反击按钮。response + value 可按时间切换：both 两者、parry 仅弹反、counter 仅反击、off 关闭；在有效窗口点击，暂停时停止，重开恢复默认。

长剧情 JSON 包含 title、recording: true、duration、p1HeroId、p2HeroId 和 timeline，加载后需播放/重开生效。短局仍使用数组，中途加载会补执行已过时的节点，可能提前结束。

标注时间为剧情秒数，短暂停顿与约 3.35 秒终结演出另计。这里只播放演出，视频请用本地录屏工具录制。
