# 🎰 神人轮盘大乱斗 (ShenRen-Roulette)

全随机盲盒 1v1 电子斗蛐蛐 × 狂暴抽卡 × 肉鸽词条 5 选 3（9:16 竖屏短视频录播专版）。

## ✨ 核心玩法

- **角色配装架构**：每个角色自带 **2 个固定核心被动** + **1 个自选普通主动技** + **1 个自选究极技（含主动大招或纯被动大招）**。
- **开局快节奏双盲盒**：
  1. **Step 1（3秒盲盒选人）**：从已解锁神人池随机跳动抽取，可点击立即锁定，超时自动随机出战。
  2. **Step 2（5秒词条 5 选 3）**：按词条等级权重从词条池随机刷出 5 个（含主动/被动），点选 3 个或超时自动补齐直接开打（局内底部最多 5 个主动按钮）。
- **全明星大混池 & 重复卡智能分流**：
  - 高概率通用词条、低概率角色专属技、低概率新角色、超低概率 UR 究极技/彩色词条。
  - **重复卡二选一**：高阶词条推荐【升级】（仅提高局内 5 选 3 刷出权重，不破坏数值平衡）；角色技能【升级】（伤害与特效规模翻倍）；均可选择【转化为保底兑换币】在商店直接强娶未拥有 UR/角色。
- **动态胜率平衡（40%~60% 自动 / 手操抓时机提胜率）**：
  - 纯自动对战通过老式 DVD 随机弹跳 + 镜像强度配平 + 劣势方橡皮筋补偿，大样本胜率稳定在 `45%~55%`。
  - 手动在两球贴脸瞬间释放技能触发 `x1.4 贴脸暴击`，或点击交锋时的 `⚡极限弹反/哈气` 按钮，可将胜率提升至 `70%+`。

## 🚀 本地运行

直接双击 `index.html` 或使用任意静态服务启动：

```bash
python3 -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765/
```

## 🎬 录屏导演快捷键

- `P`：切换纯净 9:16 录屏模式（隐藏两侧工作台）
- `Space`：暂停 / 继续
- `1 ~ 5`：键盘释放底部 1~5 号主动技能
- `Q`：【剧本】我方锁 1 滴血无敌 3.5 秒 + 全技能刷新（录制丝血逆天翻盘）
- `W`：【剧本】敌方变 1 滴血待斩杀
- `E`：【剧本】双方瞬间贴脸碰撞
- `R`：【剧本】召唤全屏大运百吨王车队冲撞
- `T`：【调试】直接赠送 50 抽卡券 + 500 保底币
- `B`：【验证】后台秒跑 200 局纯自动对战检测胜率
