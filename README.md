# 神人对决 ShenRen Roulette

原生 JavaScript + Canvas 的横屏弹球对战游戏，主舞台为 16:9。无需安装运行依赖，支持自动对战、手动闪避与弹反、五大构筑流派，以及抽卡和保底兑换。

## 本地运行

在项目目录运行：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765/ 。手机建议横屏；顶部“导演”可随时展开固定剧情面板，侧边工作台仅在超宽窗口显示。存档在当前浏览器、当前网址的 localStorage 中，不同端口或浏览器的存档相互独立。

## 玩法与节奏

- 开局有 3 秒选人和 5 秒词条选择时间；选满 3 个词条后可调整，点击立即开战或等待倒计时结束。缺少的选项随机补齐。
- 大厅提供两个模式：录屏短局上限 60 秒，基础生命 1800；构筑长局上限 300 秒，基础生命 6000。实际对局可以提前结束，装备技能等级会等比例提高双方生命。
- 前、中、后、加时阶段分别在时限的 0%、20%、60%、90% 开始，后期提高伤害，加时增加双方等比例生命消耗。
- 普通技能、治疗或控制主动成功施放后为施法者究极能量 +12；双方肉搏碰撞各 +6；成功完成究极闪避或极限弹反 +20。能量共享于角色主动究极与主动究极词条，满 100 才释放，释放前摇时立即清零；普通伤害、持续伤害和普通闪避不直接充能，镜像重放不重复触发究极。
- 主动究极核心伤害为目标最大生命 36%，按等级最多 48%；被动究极核心为 22%，按等级最多 30%。核心仍受护盾、闪避、`pk_col_5` 减伤、免死和锁血影响；每次究极的附加命中预算为目标最大生命 15%，角色究极默认 3 个附加对象，法术究极 5 个，被动究极 2 个。
- 普通技能在贴脸手动释放时有伤害加成。主动究极先播放 **0.9 秒纯特写**，再回到战场展示 **0.6 秒攻击轨迹与收缩落点圈**；特写阶段不能回避。命中前 **0.22 秒**开放 D 回避，进入窗口时以 **0.2×速度持续0.3现实秒**；暂停冻结窗口。
- 成功回避会缩小翻滚并留下残影，免除本次核心与附加攻击，命中后仍有 **0.55 秒免伤**，获得20点究极能量。最后 **0.08 秒**按 F / 空格可拆招：核心伤害减半、取消本次附加攻击，并反震核心基准伤害的10%、震退攻击者。过早拆招会消耗本次应对机会，不能再补按回避。
- 电脑和自动模式玩家会在命中时按架势与闪避词条概率尝试回避；手动模式不代按。成长型蒙多究极不造成核心伤害，也不开放敌方应对窗口。
- 六类技能动作由 `animationType` 指定：真身变大、冲刺残影、0.12秒瞬移、0.4秒三段折返、双镜像、独立召唤物。临时形变不改永久成长半径；运动技能按轨迹或重现时刻判定伤害。分身最多2个、持续0.8秒，受敌弹击中可拦截并消散；残影最多6帧，柔和特效、系统减弱动态或低核设备降为3帧并减少粒子。
- 大运车队、猫猫护卫、悬浮护航机与防守中锋统一使用 `summons`。暂停/时停遵循战斗规则，重开、离场和结算清除实体及究极应对。
- 超时按剩余生命比例加护盾比例的 15% 判定；分数相同为平局。体型成长受场地安全上限约束。

## 抽卡与奖励

单抽基础概率：UR 3%、SSR 25%、SR/R 72%。十连至少获得一张 SSR 或 UR，因此十连末张的条件概率与单抽不同。

- 普通技能等级伤害成长为 28%；被动究极核心等级成长由 `js/config.js` 的统一配置读取，最高受 30% 核心比例上限约束。重复卡选择在抽取和修改时保存，刷新后可以继续结算，已结算记录不会重复发奖。

每局结算奖励 20 张抽卡券、35 枚保底币、80 经验；每 100 经验升一级。券不足时需要完成对局，导演调试键仍可用于录制。概率和奖励均来自 `js/config.js`，界面与算法共用配置。

## 设置与快捷键

右上角设置提供音效音量、静音、技能喊话和柔和特效。设置自动保存，打开设置会暂停当前对局，关闭后恢复先前状态；同时遵循系统减少动态效果的偏好。

| 按键 | 功能 |
| --- | --- |
| H | 展开或收起导演剧情面板 |
| P | 纯净 16:9 录屏模式，隐藏周边工作台、导演入口及面板 |
| Space | 究极技期间尝试拆招；其余时间暂停或继续 |
| D | 战场命中前0.22秒内紧急回避 |
| F | 究极命中前0.08秒极限拆招；无究极时触发近身弹反 |
| 1 至 5 | 释放相应主动技能 |
| Q | 导演模式：我方 1 血锁血 3.5 秒，普通技能冷却清零并充满究极能量 |
| W | 导演模式：敌方变成 1 血 |
| E | 导演模式：双方贴脸 |
| R | 导演模式：召唤卡车车队 |
| T | 调试赠送 50 券和 500 保底币 |
| B | 使用检测面板的种子与局数运行模拟 |

顶部“导演”面板提供 Q / W / E / R 固定剧情和 T 资源调试的点击按钮；展开面板不会暂停对局。剧情仅在开战后、我方可行动时触发；暂停、眩晕、时停或大招前摇时会提示等待。触屏也可以使用顶部暂停、重开、大厅按钮。输入框、对话框及组合快捷键不会触发导演操作。

## 剧本时间轴与录屏

顶部“导演”或 H 打开剧本编辑区。五个长剧情模板已经完整编排好台词、章节、控血、护盾与技能节拍。选择模板后点击“播放剧本（纯净画面）”，即可跳过盲盒选人和选词条，按固定演员、构筑长局和 1×速度自动演出；打开本地录屏工具录制即可，不需要一路按导演快捷键。

| 长剧情 | 我方 / 对手 | 主剧情 | 预计录制时长（含停顿与终结） |
| --- | --- | --- | --- |
| 大运外卖：顾客点了外卖，大运把顾客送走了 | 大运 / 哈基米 | 120 秒 | 约 2:04 |
| 残血钓鱼：哈基米剩一滴血，对面却不敢靠近了 | 哈基米 / 大运 | 100 秒 | 约 1:44 |
| 血条账单：你以为这是血条，其实这是账单 | 肘击王 / 大运 | 140 秒 | 约 2:24 |
| 面试官下班：坤哥来面试，最后把面试官打下班了 | 坤哥 / 肘击王 | 160 秒 | 约 2:44 |
| 网线保命：这只猫把网线当保命技能 | 哈基米 / 坤哥 | 110 秒 | 约 1:56 |

长剧情仅在播放/重开时开始：双方保活到指定 `finish` 节点，不会被自然伤害、反伤或处决提前打断。画面显示持续字幕和章节，结尾台词保留到胜利演出。角色未收藏也能用于导演演出，不会永久解锁角色，亦不修改保存的模式、配装或自动施法偏好；对局仍沿用现有结算奖励。长剧情播放期间速度和自动释放开关锁定，清除剧本解除录制控制。

长剧情开局自动进入纯净画面，战斗提示与结算按钮不显示导演/剧本字样。默认在弹反按钮出现约 0.42 秒后模拟点击，在敌方究极技的有效拆招窗口自动点击反击，屏幕显示鼠标和点击反馈，并通过原有按钮事件结算。可在时间轴加入 `{ "at": 20, "action": "response", "value": "off" }` 暂停自动应对；`both` 恢复两者，`parry` 仅弹反，`counter` 仅反击。暂停时不点击，重开恢复默认，普通对局不启用。

每个长剧情由独立的 `js/stories/` 文件定义。表中的预计录制时长是不计究极慢动作的基准，包括“网线保命”的0.5/0.8/0.5秒停顿及3.35秒终结演出；每次究极慢动作在1×速度下额外增加约0.24现实秒。手动暂停、设置或浏览器后台节流也会延长录制。JSON 中的 `duration` 和字幕到期时间均按战斗时钟推进，不按现实帧数计时。

原有“逆风翻盘”“贴脸血战”“卡车派对”短模板和自由 JSON 数组仍可使用；它们只安排节点，不提供长剧情保活与固定选角。编辑后点击“加载剧本”生效，面板显示已执行、下一条和待执行状态。按 P 可切换纯净画面。

示例：先压低我方血量，再锁血反击、贴脸、召唤车队，最后击倒敌方。

```json
[
  { "at": 0, "action": "text", "content": "逆风局开始" },
  { "at": 6, "action": "hp", "target": "p1", "value": 0.25 },
  { "at": 9, "action": "q" },
  { "at": 12, "action": "e" },
  { "at": 14, "action": "r" },
  { "at": 18, "action": "hp", "target": "p2", "value": 0 }
]
```

| action | 参数与效果 |
| --- | --- |
| `q` / `w` / `e` / `r` | 与手动导演按钮共用指令：我方锁血并就绪技能、敌方 1 血、双方贴脸、四路卡车 |
| `hp` / `shield` | `target` 为我方 `p1` 或敌方 `p2`；`value` 在 0 到 1 时为最大生命/护盾的比例，大于 1 时为绝对值，均不超过上限。`hp` 的 0 会立即击倒 |
| `ult` | 指定 `target`，充满究极能量，不强制施法；后续释放仍遵循自动/手动操作与行动规则 |
| `stun` | 指定 `target` 和非负 `duration`，眩晕若干对局秒；0 表示立即解除眩晕 |
| `speed` | `value` 为 0.5、1、1.5 或 2，同步更新播放倍率和速度选择器；录制长剧情固定 1× |
| `text` | `content` 为文字，可附 `color`（CSS 颜色字符串）；在战场上显示漂字 |
| `pause` | 正数 `duration` 为现实秒，冻结对局后自动继续；手动暂停/继续或打开设置会接管暂停，取消这次自动恢复 |
| `caption` | `content`、正数 `duration`，可附 `chapter` 和 `color`；显示持续字幕，暂停时保持，按对局时间到期 |
| `guard` | 仅长剧情：`target` 和 0–1 的 `value` 设置最低生命比例；0 仍保留至少 1 生命直到收尾 |
| `finish` | 仅长剧情：在 `duration` 秒指定 `target` 退场；必须是唯一且最后的节点，按时进入原有终结与结算 |

时间与边界：

- `at` 是开战后的对局秒数，不含选人、选词条或暂停时间；变速会改变现实播放时间。同秒节点按书写顺序执行，0 秒节点在开战时执行。
- 短局数组里的 `q/w/e/r` 若遇到眩晕、时停或大招前摇，会顺序等待恢复，实际执行可能晚于 `at`。长剧情则将它们作为导演调度按时执行；普通技能与究极释放仍遵循角色真实的施法规则，`ult` 只补能。
- 短局数组中途加载以本局开战为起点，过时节点会在下一次更新补执行；加载长剧情会停止当前对局并准备新剧本，须点击播放或重开。编辑文本不会修改已加载剧本。
- 重开从头执行。长剧情重播固定为 1×，短局恢复加载时的初始速度；清除会取消定时暂停、撤销保活和速度锁并恢复原倍率，同时保留编辑区。“清空自定义”同时清空编辑区。
- `hp.value: 1` 表示满血，不是 1 血；真正 1 血请用 `q`（我方）或 `w`（对手），不能通过 `w` 的 target 参数改为我方。长剧情禁止提前 `hp: 0`，只用末节点 `finish` 收尾；自由数组的 0 会立即击倒并停止后续剧情，不能复活死亡角色。无界面运行跳过 `pause` 的现实等待。
- 这是明确标注的导演演出，不是自然语言 AI 编剧或竞技胜负回放。长剧情控制存活与收尾，但角色轨迹、技能命中与究极动画仍取决于真实战斗和当前配装，不保证每次画面逐帧相同。账单和“网络卡顿”是演出台词/暂停，不是真的计费或断网。

“导出 JSON”保存编辑区的有效剧本，不会导出视频，也不会重新加载或改变当前对局；“导入 JSON”校验后填入并加载。无效 JSON、未知动作或错误参数不会替换当前剧本。剧本不写入游戏存档，刷新前请导出需要保留的内容。

长剧情导入/导出保留完整对象：`{ "title": "剧情名", "recording": true, "duration": 120, "p1HeroId": "dayun", "p2HeroId": "hajimi", "timeline": [...] }`。`duration` 及所有停顿加 3.35 秒收尾不得超过 180 秒；演员 ID、参数、字幕时长、唯一终点都必须通过校验。自由短剧本则保持数组格式。公开发布录屏前请确认角色图、配音、音乐的使用授权，来源记录不等于发布授权。

## 平衡检测

战斗界面新增双方发育栏：显示普通/究极技能等级、普通伤害倍率、常驻减伤、体型，以及相对开局的生命上限和基础移速变化。点击任一发育栏打开详细属性，查看生命、护盾、究极能量、属性来源、最近八条成长和最近三次大招；查看时暂停，关闭或按 Esc 恢复打开前的暂停状态。普通技能仍使用冷却，没有新增魔法值资源。

生命栏下显示当前剧情锁血下限及免死保护。技能栏上方保留双方最近大招结算，按释放序列累计实际扣血、护盾吸收、减伤、保护拦截与触发回血；回避、拆招和成长型究极分别说明原因。扣血不含溢出伤害，多段持续累计；完整记录可在属性面板查看。这里只增加可视化记录，不修改伤害倍率或剧情锁血规则。

大厅点击“平衡检测”，选择种子和 200 或 1000 局样本。模拟使用当前存档的快照和独立战斗实例，双方强制自动施法，不改变当前对局或存档。

模拟与实战共用 60Hz 固定步长、施法等待、大招前摇和伤害规则。随机数与绘制、音效随机数分开，同种子和同一存档可复现结果。报告包含整体胜率、平局、平均时长、超时率、结束阶段，以及角色、流派 UP、装备技能平均等级分组。分组流派表示选词条时的权重倾向，不保证最终三个词条同属该流派；小样本不能证明所有组合都平衡。

### 新角色与素材维护

新增角色只需在 `js/data.js` 的 `MEME_DATA.heroes` 加入角色对象；大厅、抽卡、存档初始化、模拟器和战斗创建均按角色表动态遍历，不要新增角色数量硬编码。优先复用已有 `effectKind`；新增效果时同步更新 `js/effects.js` 或 `js/battle.js` 与回归场景。

角色素材按类型放入 `assets/images/`、`assets/sounds/`，GIF/视频仅在确有必要且体积可接受时加入。每项资源都要在 `assets/sources/manifest.json` 登记原始来源、作者、许可证、下载日期、处理方式和授权状态；许可证不明使用 `review-required`，来源记录不等于授权。新增角色的设计、资源检索和接入清单见 `.agents/skills/meme-character-designer/SKILL.md`。

使用 Node.js 运行回归检查，无需安装 npm 依赖：

```sh
node --test tests/regression.test.cjs
```

测试覆盖抽卡恢复、保底、旧存档兼容、重开、暂停、闪避、免死、词条效果、结算幂等、实战与模拟的逻辑一致性，以及剧本排序、输入隔离、暂停接管、重开、技能就绪和击倒后的终止行为。`npm test` 等价。

可选素材放置在 `assets/images/{character-id}.png` 和 `assets/sounds/{character-id}.mp3`；没有外部素材时使用内置图形和合成音效。GIF/视频与来源记录按 `skills/meme-character-designer/SKILL.md` 执行。
